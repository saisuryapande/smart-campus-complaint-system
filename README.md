# Smart Campus Complaint Redressal System

A full-stack web application for managing student complaints with role-based authentication (Student/Admin).

## 🚀 Live Demo
[Click here to view live website](https://smart-campus-complaint.onrender.com)

## 📋 Features
- User authentication (Student/Admin login & registration)
- Students can submit and track complaints
- Admin dashboard with complaint management
- Role-based access control
- Responsive UI with Bootstrap

## 🛠️ Tech Stack
| Layer | Technology |
|-------|------------|
| Backend | Java, Spring Boot, Spring Data JPA |
| Frontend | Thymeleaf, Bootstrap, HTML, CSS |
| Database | MySQL |
| Deployment | Render.com |
